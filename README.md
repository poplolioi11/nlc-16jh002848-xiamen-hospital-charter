# 厦門中山醫院董事會組織大綱（中國國家圖書館 官/419.6/8312，1929）

*Xiamen Zhongshan Hospital Board Charter (1929)*

廈門市衛生會印行的 1929 年《廈門中山醫院計劃書》收入院務緣起、籌建預算、董事會規章及募捐組織。〈厦門中山醫院董事會組織大綱〉是其中一篇，八條規範董事選任、捐助與董事資格、任期、會議、院務監督和經費籌措。可用於檢索民國初期廈門醫院籌建與公共慈善治理。

本版取中國國家圖書館藏本的 PDF 第 33–34 頁，轉錄原印頁一的標題與八條全文，記錄原印頁二的欄題與附圖位置。提供 JSON、逐欄及連讀 TXT、TEI P5。第 2 條金額經兩份依圖讀稿比對後回圖核為「一萬元」。本版採 AI 輔助讀字，尚無人類全文雙校、專家審定或準確率量測。
